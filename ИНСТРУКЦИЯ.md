# Наша кухня: как запустить

Приложение уже работает **на этом компьютере**: откройте `index.html` двойным кликом.
Пока данные хранятся только в этом браузере (в шапке написано «локально»).

Чтобы пользоваться вдвоём с телефонов, нужно пройти 4 шага, примерно 20–30 минут. Всё бесплатно.

| Шаг | Что даёт |
|---|---|
| 1. GitHub Pages | сайт по адресу `https://ВАШ-НИК.github.io/recipes/`, установка на телефон |
| 2. Supabase | общая база для двоих, вход по почте и паролю, загрузка рецептов по ссылке |
| 3. Telegram-бот | напоминания о сроках заготовок и заморозки |
| 4. Секреты в GitHub | ежедневная проверка сроков в 9:00 по Москве |

---

## Шаг 1. GitHub: публикуем сайт

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Справа вверху **+ → New repository**:
   - Repository name: `recipes`
   - **Public** (бесплатный GitHub Pages работает только с публичными репозиториями; ваши данные будут не в репозитории, а в Supabase, так что видна только программа)
   - Create repository
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** папки `приложение с рецептами`: `index.html`, `sw.js`, `manifest.webmanifest`, папки `css`, `js`, `icons`, `scripts`, `supabase`, `.github`. Внизу нажмите **Commit changes**.
   > Если папка `.github` не загрузилась (так бывает со скрытыми папками), создайте файл вручную: **Add file → Create new file**, в имени напишите `.github/workflows/reminders.yml`, вставьте содержимое одноимённого файла с компьютера и нажмите Commit.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/recipes/`.

---

## Шаг 2. Supabase: общая база

1. Зарегистрируйтесь на https://supabase.com (удобно через кнопку «Continue with GitHub»).
2. **New project**: имя `kuhnya`, придумайте пароль базы и сохраните его, Region: **Central EU (Frankfurt)**. Нажмите Create и подождите около минуты.
3. **Создаём таблицы.** Слева **SQL Editor → New query**. Откройте файл `supabase/schema.sql`, впишите в нём **ваши две почты** вместо `ваша-почта@example.com` и `почта-жены@example.com`, вставьте весь текст и нажмите **Run**. Должно появиться «Success».
4. **Закрываем регистрацию для посторонних.** **Authentication → Sign In / Providers** (или Settings) → выключите **Allow new users to sign up** → Save.
5. **Заводим вас двоих.** **Authentication → Users → Add user → Create new user**: почта и пароль, галочка **Auto Confirm User**. Повторите для жены. Почты должны совпадать с теми, что вы вписали в `schema.sql`.
6. **Подключаем сайт к базе.** **Project Settings → API** (или Data API / API Keys). Скопируйте:
   - **Project URL** (вида `https://abcd1234.supabase.co`)
   - ключ **anon public** (длинная строка, начинается с `eyJ…`)

   На GitHub откройте файл `js/config.js` → значок карандаша ✏️ → вставьте значения между кавычками:
   ```js
   supabaseUrl: 'https://abcd1234.supabase.co',
   supabaseAnonKey: 'eyJhbGciOi...',
   ```
   Нажмите **Commit changes**. Anon-ключ публичный, его можно хранить в открытом репозитории: без вашей почты и пароля он ничего не открывает.
   ⚠️ Ключ **service_role** сюда **никогда** не вставляйте, он нужен только на шаге 4.
7. **Загрузка рецептов по ссылке.** **Edge Functions → Deploy a new function → Via Editor**. Удалите пример кода, вставьте содержимое файла `supabase/functions/import-recipe/index.ts` и нажмите **Deploy**. Имя функции, которое покажет Supabase (например `rapid-action`), впишите в `js/config.js` в строку `importFunction`.
8. Откройте сайт, войдите под своей почтой и паролем.
   - Если на компьютере уже что-то накопилось локально: в старой версии откройте **Настройки → Сохранить копию**, а в новой **Настройки → Загрузить копию**.
   - Ваши блюда из «Меню недели» добавляются одной кнопкой на пустой странице «Рецепты» (или в «Настройках»).

## Шаг 3. Telegram-бот для напоминаний

1. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя (например «Наша кухня») и адрес (например `nasha_kuhnya_ivanovy_bot`). BotFather пришлёт **токен** вида `123456789:AAH…`, сохраните его.
2. Создайте группу в Telegram (например «Кухня»), добавьте в неё жену и вашего бота. Напишите в группе любое сообщение.
3. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates`, подставив свой токен. Найдите `"chat":{"id":-100…`. Это **id чата** (с минусом).
   > Можно и без группы: каждый пишет боту `/start` в личку, и в getUpdates появятся два id. Впишите оба через запятую.

---

## Шаг 4. Секреты в GitHub: включаем ежедневные напоминания

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте 4 секрета:

| Name | Значение |
|---|---|
| `SUPABASE_URL` | Project URL из шага 2.6 |
| `SUPABASE_SERVICE_KEY` | ключ **service_role** (Supabase → Project Settings → API). Секретный, только сюда! |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_IDS` | id чата (или два id через запятую) |

На вкладке **Variables** можно добавить, но это необязательно:
- `APP_URL`: `https://ВАШ-НИК.github.io/recipes/` (тогда в сообщении будет ссылка на приложение)
- `REMIND_DAYS`: за сколько дней начинать напоминать (по умолчанию 3)

Проверка: вкладка **Actions** → «Напоминания о сроках» → **Run workflow**. Если есть заготовки, у которых срок подходит к концу, в Telegram придёт сообщение. Дальше проверка запускается сама каждый день в 9:00 по Москве.

> Две особенности бесплатных тарифов:
> - Бесплатный проект Supabase «засыпает», если к нему неделю никто не обращался. Ежедневная проверка сроков как раз обращается к нему, так что он не уснёт.
> - GitHub может отключить расписание, если в репозитории 60 дней не было изменений. Он пришлёт письмо, и достаточно нажать **Enable workflow** во вкладке Actions.

## Установка на телефон (PWA)

Откройте `https://ВАШ-НИК.github.io/recipes/` на телефоне:
- **iPhone (Safari):** кнопка «Поделиться» → **На экран «Домой»**
- **Android (Chrome):** меню ⋮ → **Установить приложение** (или кнопка в «Настройках» приложения)

Появится иконка «Наша кухня». Приложение открывается на весь экран, а без интернета показывает последние загруженные данные.

## Что где в приложении

- **Рецепты**: таблица всех рецептов. Новые попадают в «Не пробовали», после готовки можно отметить ❤ «Понравилось» или «Не зашло». В карточке рецепта видно, каких продуктов нет дома, и их можно одной кнопкой добавить в покупки.
- **Меню**: блюда на неделю (завтрак, обед, ужин). «Заполнить пустое» подбирает блюда автоматически, «Продукты на неделю в покупки» собирает список недостающего.
- **Подбор**: «Из того, что есть» показывает рецепты, для которых меньше всего нужно докупить. «С выбранными продуктами» показывает рецепты с нужным продуктом (например, чтобы пристроить кабачок).
- **Продукты**: «Есть дома» и справочник примерно на 450 ингредиентов. Можно добавлять свои.
- **Покупки**: список «Купить». То, что отметили купленным, попадает в «Есть дома» и в историю с датой (её можно поправить, можно указать цену). Внизу «Часто покупаем».
- **Заготовки**: «Для нас» и «Для Саввы», заморозка и банки, дата изготовления и срок годности. Предупреждение в приложении появляется за 7 дней, в Telegram за 3. Кнопка 📅 добавляет напоминание в Google Календарь.

- **Готовлю** (кнопка в рецепте): экран не гаснет, шаги крупно, ингредиенты можно вычёркивать, а время из шагов («варить 20 минут») запускается таймером со звуком.
- **Наши блюда с полными рецептами.** У 80 блюд из «Меню недели» есть шаги приготовления, время и полный состав. Если блюда добавлены раньше и шагов в них нет: Настройки → «Резервная копия» → «Дополнить наши блюда полными рецептами». Ваши правки состава и свои шаги не затираются.
- **Граммы**: у ложек, стаканов и штук мелко в скобках написан примерный вес (2 стакана муки ≈320 г, 1 яйцо ≈55 г). Стакан считается 250 мл, ложки — с небольшой горкой.
- **Свои количества** (в рецепте и в режиме «Готовлю»): нажмите на подчёркнутое количество, впишите, сколько у вас (можно в граммах), и выберите «Пересчитать весь рецепт» или «Изменить только этот продукт». Порции меняются кнопками − / +. Если продукта дома не хватает, сверху появится «хватит примерно на N порций» с кнопкой пересчёта. Граммовки в тексте шагов пересчитываются и подсвечиваются. «Вернуть как в рецепте» отменяет правки.
- **Приготовили**: записывает дату, спрашивает «как вам?» и списывает продукты из «Есть дома» в том количестве, которое вы реально взяли (с учётом правок; ложки и штуки переводятся в граммы, если дома записано в г/кг). Галочка «Сохранить мои количества в рецепт» запоминает их, а старые записывает в заметки. Меню реже предлагает то, что готовили на днях.
- **Покупки → Отправить список**: текст списка в Telegram или WhatsApp.
- **Без интернета**: изменения сохраняются на телефоне, вверху видно «не отправлено: N». Когда появится сеть, они уйдут сами.

## Вечернее сообщение (19:00)

- Если в меню на завтра есть блюдо, которое лежит в морозилке, бот напоминает его достать. Блюдо и заготовка связываются, если заготовку сделали кнопкой «Сделали заготовку» в рецепте или если названия совпадают («Котлеты домашние» подходит к «Котлеты»). В меню такие блюда отмечены ❄.
- По воскресеньям бот присылает меню на следующую неделю и список того, чего не хватает.
- Workflow: `.github/workflows/evening.yml`. Проверка: Actions → «Вечернее сообщение» → Run workflow (с галочкой меню пришлёт сразу).

## Версия для компьютера

Адрес: `https://ВАШ-НИК.github.io/recipes/desktop.html`. Данные те же, что на телефонах. Установка как отдельная программа: Chrome или Edge → значок установки в адресной строке (монитор со стрелкой). Ярлык появится на рабочем столе и в «Пуске».

Что есть только там:
- **Ctrl + V в любом месте:** вставить рецепт из скопированного текста, скриншота или ссылки. Фото чека с QR-кодом распознается как чек. Если форма рецепта уже открыта, вставленное допишется в неё: так собирается длинное описание из нескольких скриншотов.
- **Перетаскивание файлов в окно:** txt, pdf, Word, скриншоты, фото чеков, таблицы Excel. Несколько скриншотов одного рецепта собираются в один рецепт, несколько чеков обрабатываются по очереди.
- **Закладка «В Нашу кухню»** (Инструменты): перетащите кнопку на панель закладок. На странице рецепта или в посте Instagram нажмите закладку, и рецепт откроется в приложении. Если подтянулось не то, выделите текст рецепта мышкой и нажмите закладку ещё раз.
- **Меню недели таблицей:** перетаскивание блюд из списка слева и между днями, стрелки ← → листают недели.
- **Печать и PDF:** рецепт, меню недели с покупками, список покупок, книга любимых рецептов (Ctrl + P печатает текущую страницу).
- **Excel:** выгрузка всего; загрузка рецептов, таблиц вроде «Меню недели.xlsx» и меню по датам.
- **Аналитика:** бюджет на месяц с прогнозом, траты по неделям, магазины, динамика цен за кг или л.
- **Массовая правка:** галочки слева в списке рецептов, затем категория или статус сразу для многих, печать или удаление.
- **Горячие клавиши:** N — новый рецепт, / — поиск, Alt + 1…8 — разделы, Ctrl + Enter — сохранить, ? — подсказка.

## Рецепты из файлов

**Рецепты → «Из файла»** (или кнопка «Из файла» в форме рецепта). Подходят txt, pdf, Word (.docx), html и фото страницы из книги или со скриншота.
- Один файл: откроется форма с заполненными названием, ингредиентами, шагами, порциями и временем. Проверьте и сохраните.
- Несколько файлов сразу: все добавятся в «Не пробовали».
- Сканированный PDF и фото распознаются прямо в телефоне. Старый .doc и .rtf не читаются: сохраните их как .docx или .txt.

В окне выбора блюда впишите любое название и нажмите «Добавить … без рецепта». Такие блюда потом подсказываются при наборе. Если нажать на него в меню, можно «Создать рецепт», и все одноимённые блюда в меню станут ссылкой на него.

## Чеки

**Покупки → «Чек»** → сфотографируйте чек (длинный можно частями, выбрав несколько фото).
- Из QR-кода берутся точные сумма, дата и время. Если QR не прочитался, дата и «Итог» берутся из текста чека.
- Позиции и цены читает нейросеть PP-OCR прямо на устройстве, фото никуда не отправляется. В первый раз загрузится модель (около 20 МБ, лучше по Wi-Fi), дальше она хранится в памяти и работает без интернета. Если модель не загрузилась, чек читается прежним способом (Tesseract), он заметно слабее.
- Каждая позиция проверяется арифметикой: «количество × цена = сумма». Если одна цифра прочиталась неверно, она исправляется сама, а весь чек сверяется с итогом.
- **Точные данные из ФНС (по желанию).** Сервис [proverkacheka.com](https://proverkacheka.com) по реквизитам чека отдаёт его из базы налоговой: точные названия, количества и цены. Приложение берёт реквизиты из QR-кода, а если он не прочитался — из нижней строки чека (ФН, ФД, ФП). Как включить:
  1. Зарегистрируйтесь на proverkacheka.com.
  2. В личном кабинете: профиль → «Изменить» → «Токен доступа к API» → «Генерировать». Скопируйте токен.
  3. В приложении: Настройки → «Чеки: точные данные из ФНС» → вставьте токен → «Сохранить». Достаточно сделать это на одном телефоне: токен хранится в общей базе и виден только вам двоим.
  Дальше после фото чека появится «Проверено по базе ФНС». Бесплатно сервис даёт ограниченное число запросов в сутки (около 15). Если ФНС ещё не получила чек (бывает в первые часы после покупки), приложение покажет распознанное с фото и кнопку «Повторить запрос».
- **Проверка распознавания:** Настройки → «Проверить распознавание на своих чеках» → выберите фото нескольких чеков. Приложение распознает каждый и покажет, сколько сумм совпало и где ошиблось в названиях (с токеном ФНС — сверка по каждой позиции, без токена — только с «Итогом»). В покупки при этом ничего не записывается. Каждый чек, сверенный с ФНС при обычном сканировании, тоже попадает в эту статистику.
- **Продукт подбирается из справочника как можно точнее:** «Свинина охл Лопатка н.к» → «свинина лопатка», «Шея свиная» → «свинина шея», «Филе цыплёнка-бройлера» → «куриное филе», «Сыр Гауда 48%» → «сыр гауда». В справочнике около 1000 продуктов: все части говядины, свинины, баранины, птицы, колбасы, рыба, молочное, сыры, заморозка, хозяйственные товары.
- Приложение запоминает, как вы назвали строку чека («Свинина охл лопатка н.к» → «свинина»), и в следующий раз подставит это название само.
- На экране проверки поправьте названия и снимите галочки с лишнего. Если позиции дороже чека, это скидка: кнопка разнесёт её по позициям. Если дешевле, значит, какая-то строка не распозналась, её нужно дописать.
- После сохранения позиции попадают в историю и «Расходы» (там же разбивка по магазинам), отмечаются купленными в списке покупок и добавляются в «Есть дома».
- Если позиции не распознались совсем, чек можно сохранить одной суммой.
- Снимайте ровно, при хорошем свете, весь чек в кадре.

### Как сфотографировать чек, чтобы он хорошо распознался

Главное — **размер букв на фото**. Длинный чек одним кадром получается мелким, и названия читаются с ошибками (цифры при этом обычно верные). Поэтому длинный чек снимайте по частям (пункт 5). И загружайте **исходное фото с телефона**: пересланное через мессенджер сжимается в несколько раз.

1. Положите чек на ровный стол и расправьте (цвет стола теперь не важен). Мятые сгибы дают ошибки в цифрах.
2. Снимайте **сверху, прямо**. Небольшой наклон приложение выровняет само. Чек должен занимать почти весь кадр.
3. Нужен **хороший свет без бликов и тени от телефона**: у окна днём или под лампой сбоку. Вспышку лучше не включать, термобумага бликует.
4. **QR-код** обязательно в кадре и в фокусе, из него берутся точная сумма и дата.
5. **Длинный чек** снимайте 2–3 фото с небольшим перекрытием и выбирайте их все сразу: Покупки → «Чек» → отметить несколько фото.
6. Выцветший чек сканируйте как можно скорее: через пару недель термобумага бледнеет.

### Что делать на экране проверки

- **Зелёное «сходится ✓»:** всё распозналось, нажимайте «Сохранить».
- **«Больше на N ₽»:** на чеке была скидка. Нажмите «Учесть скидку: разнести по позициям».
- **«Меньше на N ₽»:** какая-то строка не распозналась. Откройте «Распознанный текст» внизу, найдите её и добавьте кнопкой «Добавить строку».
- **Название распозналось криво** («МОЛ.ПРОСТ»): поправьте вручную, при наборе есть подсказки из справочника. Мелким шрифтом под названием видна исходная строка чека.
- **Лишняя строка** (пакет, бонусы): снимите у неё галочку.
- **Ничего не распозналось:** переснимите при лучшем свете или нажмите «Одной суммой», и чек попадёт в расходы без разбивки.
- Перед сохранением проверьте галочки «Отметить купленным в списке покупок» и «Добавить в „Есть дома“».

## Рецепт из Instagram

Прямая загрузка по ссылке из Instagram **не работает**: Instagram пускает только после входа в аккаунт, и автоматически текст поста забрать нельзя (к тому же в России он открывается только через VPN). Ссылку на пост приложение и бот сохранят, но ингредиенты не подтянут. Рабочие способы:

**Способ 1. Скриншот (с телефона, проще всего)**
1. Откройте пост, нажмите «ещё» под описанием, чтобы раскрыть текст полностью.
2. Сделайте скриншот описания. Если текст длинный, сделайте несколько и обрежьте лишнее (верх и низ экрана).
3. Рецепты → **«Из файла»** → выберите скриншот. Текст распознается и разложится на ингредиенты и шаги.
4. Проверьте форму. В поле «Ссылка на рецепт» вставьте ссылку на пост (⋯ → «Копировать ссылку»), чтобы видео было под рукой. Кнопку «Загрузить» не нажимайте. Сохраните.

Важно: если выбрать в «Из файла» **несколько скриншотов сразу**, каждый станет отдельным рецептом. Для длинного описания добавляйте первый скриншот через «+ Рецепт» → «Из файла», а остальной текст допишите в поля вручную.

**Способ 2. Копирование текста (удобно на компьютере)**
1. Откройте пост на instagram.com, выделите текст описания мышкой, скопируйте (Ctrl+C).
2. В приложении нажмите «+ Рецепт», вставьте ингредиенты в поле «Ингредиенты» (по одному в строке), шаги в «Приготовление», ссылку на пост в «Ссылка на рецепт».
   Или вставьте весь текст в Блокнот, сохраните как `.txt` и загрузите через «Из файла»: тогда разбивка на ингредиенты и шаги сделается сама.

**Способ 3. Закладка на компьютере (удобнее всего)**
В версии для компьютера: Инструменты → перетащите кнопку «В Нашу кухню» на панель закладок. Откройте пост в Instagram (в браузере, где вы вошли в аккаунт) и нажмите закладку: описание поста откроется в приложении уже разобранным на ингредиенты и шаги. Если подтянулось лишнее, выделите мышкой только текст рецепта и нажмите закладку снова. Ещё можно скопировать текст или скриншот и нажать Ctrl + V прямо в приложении.

**Совет:** если автор пишет «рецепт в комментариях» или «в профиле», скриншотьте именно этот текст. На видео без текста рецепта распознавать нечего.

## Фото блюд

Один раз: Supabase → **SQL Editor → New query** → вставить `supabase/photos.sql` → **Run**. После этого в рецепте появится кнопка «Добавить фото блюда» (с камеры или из галереи). Фото сжимаются примерно до 200–300 КБ.

## Бот принимает сообщения

Пишете боту «молоко 2 л, хлеб», и это добавляется в покупки. Ссылка на рецепт добавляет рецепт, `/список` присылает текущий список. Бот отвечает только вашим двум чатам.

Подключение (один раз):
1. Supabase → **Edge Functions → Deploy a new function → Via Editor**, вставить `supabase/functions/telegram-bot/index.ts`, **Deploy**. Запомните имя функции и её адрес (`https://…supabase.co/functions/v1/ИМЯ`).
2. В настройках этой функции выключите **Verify JWT** (Enforce JWT verification), иначе Telegram получит отказ.
3. **Edge Functions → Secrets** (или Settings → Edge Functions → Secrets), добавить:
   - `TELEGRAM_BOT_TOKEN`: токен бота;
   - `TELEGRAM_CHAT_IDS`: два id через запятую, как в GitHub;
   - `TELEGRAM_WEBHOOK_SECRET`: любая длинная строка из латинских букв и цифр;
   - `APP_URL`: адрес сайта (необязательно, для ссылок в ответах).
4. Открыть в браузере (подставив свои значения):
   `https://api.telegram.org/botТОКЕН/setWebhook?url=АДРЕС_ФУНКЦИИ&secret_token=СЕКРЕТ`
   Ответ `"ok":true` означает, что подключено. Напишите боту `/start`.

## Резервная копия

Каждое воскресенье в 10:00 бот присылает в Telegram файл `nasha-kuhnya-ДАТА.json` со всеми данными. Восстановление: **Настройки → Загрузить копию**, выбрать этот файл. Workflow: `.github/workflows/backup.yml`, секреты те же, что у напоминаний.

## Если без VPN не синхронизируется

Как работает синхронизация: любое изменение сразу сохраняется на устройстве и видно на экране, а в базу уходит в фоне. При плохой связи приложение не «висит»: запросы ограничены по времени, неотправленное лежит в очереди и досылается само. Вверху появляется значок, только если что-то не так: «нет сети», «база не отвечает», «нет доступа к базе». Нажатие на него запускает синхронизацию.

**Проверка.** Настройки → «Проверить связь». Сделайте её дважды: без VPN и с VPN.
- Всё зелёное без VPN — связь в порядке.
- «База напрямую: короткий запрос» проходит, а «База напрямую: данные» или «Cloudflare: 100 КБ» нет — оператор обрывает большие ответы от Cloudflare, на котором работает Supabase.
- Не проходит даже короткий запрос к базе — Supabase у оператора закрыт полностью.

В обоих случаях нужен посредник в Яндекс Облаке: телефон обращается к нему, а он — к Supabase. Пошагово: файл **«ИНСТРУКЦИЯ Яндекс Облако.md»**.

## Как обновлять сайт

В папке проекта есть папка **«для GitHub»**: в ней ровно то, что должно лежать на сайте, без служебных файлов.
1. Если что-то менялось, сначала дважды щёлкните **«Собрать папку для GitHub.cmd»**: папка пересоберётся.
2. GitHub → репозиторий `recipes` → **Add file → Upload files**.
3. Откройте папку «для GitHub», выделите всё (**Ctrl + A**) и перетащите в окно браузера → **Commit changes**.
4. Через 1–2 минуты обновите приложение (Ctrl + F5 на компьютере, на телефоне закройте и откройте).

Если папка `.github` при перетаскивании не загрузилась, это не страшно: файлы расписаний меняются редко, и можно создать их вручную (Add file → Create new file).

**Функции Supabase** (загрузка по ссылке и Telegram-бот) лежат в `supabase/functions/` и обновляются отдельно, через сайт Supabase: Edge Functions → функция → вкладка **Code** → вставить новый текст файла → **Deploy**.
