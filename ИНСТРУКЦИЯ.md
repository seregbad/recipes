# Наша кухня: как запустить

Приложение уже работает **на этом компьютере**: откройте `index.html` двойным кликом.
Пока данные хранятся только в этом браузере (в шапке написано «локально»).

Чтобы пользоваться вдвоём с телефонов, нужно пройти 4 шага, примерно 20–30 минут. Всё бесплатно.

| Шаг | Что даёт |
|---|---|
| 1. GitHub Pages | сайт по адресу `https://ВАШ-НИК.github.io/recipes/`, установка на телефон |
| 2. Supabase | общая база для двоих, вход по почте и паролю, загрузка рецептов по ссылке |
| 3. Telegram-бот | напоминания о сроках заготовок и заморозки |
| 4. Секреты в GitHub | ежедневная проверка сроков в 9:00 по Москве |

---

## Шаг 1. GitHub: публикуем сайт

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Справа вверху **+ → New repository**:
   - Repository name: `recipes`
   - **Public** (бесплатный GitHub Pages работает только с публичными репозиториями; ваши данные будут не в репозитории, а в Supabase, так что видна только программа)
   - Create repository
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** папки `приложение с рецептами`: `index.html`, `sw.js`, `manifest.webmanifest`, папки `css`, `js`, `icons`, `scripts`, `supabase`, `.github`. Внизу нажмите **Commit changes**.
   > Если папка `.github` не загрузилась (так бывает со скрытыми папками), создайте файл вручную: **Add file → Create new file**, в имени напишите `.github/workflows/reminders.yml`, вставьте содержимое одноимённого файла с компьютера и нажмите Commit.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/recipes/`.

---

## Шаг 2. Supabase: общая база

1. Зарегистрируйтесь на https://supabase.com (удобно через кнопку «Continue with GitHub»).
2. **New project**: имя `kuhnya`, придумайте пароль базы и сохраните его, Region: **Central EU (Frankfurt)**. Нажмите Create и подождите около минуты.
3. **Создаём таблицы.** Слева **SQL Editor → New query**. Откройте файл `supabase/schema.sql`, впишите в нём **ваши две почты** вместо `ваша-почта@example.com` и `почта-жены@example.com`, вставьте весь текст и нажмите **Run**. Должно появиться «Success».
4. **Закрываем регистрацию для посторонних.** **Authentication → Sign In / Providers** (или Settings) → выключите **Allow new users to sign up** → Save.
5. **Заводим вас двоих.** **Authentication → Users → Add user → Create new user**: почта и пароль, галочка **Auto Confirm User**. Повторите для жены. Почты должны совпадать с теми, что вы вписали в `schema.sql`.
6. **Подключаем сайт к базе.** **Project Settings → API** (или Data API / API Keys). Скопируйте:
   - **Project URL** (вида `https://abcd1234.supabase.co`)
   - ключ **anon public** (длинная строка, начинается с `eyJ…`)

   На GitHub откройте файл `js/config.js` → значок карандаша ✏️ → вставьте значения между кавычками:
   ```js
   supabaseUrl: 'https://abcd1234.supabase.co',
   supabaseAnonKey: 'eyJhbGciOi...',
   ```
   Нажмите **Commit changes**. Anon-ключ публичный, его можно хранить в открытом репозитории: без вашей почты и пароля он ничего не открывает.
   ⚠️ Ключ **service_role** сюда **никогда** не вставляйте, он нужен только на шаге 4.
7. **Загрузка рецептов по ссылке.** **Edge Functions → Deploy a new function → Via Editor**. Удалите пример кода, вставьте содержимое файла `supabase/functions/import-recipe/index.ts` и нажмите **Deploy**. Имя функции, которое покажет Supabase (например `rapid-action`), впишите в `js/config.js` в строку `importFunction`.
8. Откройте сайт, войдите под своей почтой и паролем.
   - Если на компьютере уже что-то накопилось локально: в старой версии откройте **Настройки → Сохранить копию**, а в новой **Настройки → Загрузить копию**.
   - Ваши блюда из «Меню недели» добавляются одной кнопкой на пустой странице «Рецепты» (или в «Настройках»).

## Шаг 3. Telegram-бот для напоминаний

1. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя (например «Наша кухня») и адрес (например `nasha_kuhnya_ivanovy_bot`). BotFather пришлёт **токен** вида `123456789:AAH…`, сохраните его.
2. Создайте группу в Telegram (например «Кухня»), добавьте в неё жену и вашего бота. Напишите в группе любое сообщение.
3. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates`, подставив свой токен. Найдите `"chat":{"id":-100…`. Это **id чата** (с минусом).
   > Можно и без группы: каждый пишет боту `/start` в личку, и в getUpdates появятся два id. Впишите оба через запятую.

---

## Шаг 4. Секреты в GitHub: включаем ежедневные напоминания

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте 4 секрета:

| Name | Значение |
|---|---|
| `SUPABASE_URL` | Project URL из шага 2.6 |
| `SUPABASE_SERVICE_KEY` | ключ **service_role** (Supabase → Project Settings → API). Секретный, только сюда! |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_IDS` | id чата (или два id через запятую) |

На вкладке **Variables** можно добавить, но это необязательно:
- `APP_URL`: `https://ВАШ-НИК.github.io/recipes/` (тогда в сообщении будет ссылка на приложение)
- `REMIND_DAYS`: за сколько дней начинать напоминать (по умолчанию 3)

Проверка: вкладка **Actions** → «Напоминания о сроках» → **Run workflow**. Если есть заготовки, у которых срок подходит к концу, в Telegram придёт сообщение. Дальше проверка запускается сама каждый день в 9:00 по Москве.

> Две особенности бесплатных тарифов:
> - Бесплатный проект Supabase «засыпает», если к нему неделю никто не обращался. Ежедневная проверка сроков как раз обращается к нему, так что он не уснёт.
> - GitHub может отключить расписание, если в репозитории 60 дней не было изменений. Он пришлёт письмо, и достаточно нажать **Enable workflow** во вкладке Actions.

## Установка на телефон (PWA)

Откройте `https://ВАШ-НИК.github.io/recipes/` на телефоне:
- **iPhone (Safari):** кнопка «Поделиться» → **На экран «Домой»**
- **Android (Chrome):** меню ⋮ → **Установить приложение** (или кнопка в «Настройках» приложения)

Появится иконка «Наша кухня». Приложение открывается на весь экран, а без интернета показывает последние загруженные данные.

## Что где в приложении

- **Рецепты**: таблица всех рецептов. Новые попадают в «Не пробовали», после готовки можно отметить ❤ «Понравилось» или «Не зашло». В карточке рецепта видно, каких продуктов нет дома, и их можно одной кнопкой добавить в покупки.
- **Меню**: блюда на неделю (завтрак, обед, ужин). «Заполнить пустое» подбирает блюда автоматически, «Продукты на неделю в покупки» собирает список недостающего.
- **Подбор**: «Из того, что есть» показывает рецепты, для которых меньше всего нужно докупить. «С выбранными продуктами» показывает рецепты с нужным продуктом (например, чтобы пристроить кабачок).
- **Продукты**: «Есть дома» и справочник примерно на 450 ингредиентов. Можно добавлять свои.
- **Покупки**: список «Купить». То, что отметили купленным, попадает в «Есть дома» и в историю с датой (её можно поправить, можно указать цену). Внизу «Часто покупаем».
- **Заготовки**: «Для нас» и «Для Саввы», заморозка и банки, дата изготовления и срок годности. Предупреждение в приложении появляется за 7 дней, в Telegram за 3. Кнопка 📅 добавляет напоминание в Google Календарь.

- **Готовлю** (кнопка в рецепте): экран не гаснет, шаги крупно, ингредиенты можно вычёркивать, а время из шагов («варить 20 минут») запускается таймером со звуком.
- **Приготовили**: записывает дату, спрашивает «как вам?» и списывает продукты из «Есть дома». Количество вычитается, где его можно посчитать (1 кг − 400 г = 0,6 кг). Меню реже предлагает то, что готовили на днях.
- **Покупки → Отправить список**: текст списка в Telegram или WhatsApp.
- **Без интернета**: изменения сохраняются на телефоне, вверху видно «не отправлено: N». Когда появится сеть, они уйдут сами.

## Резервная копия

Каждое воскресенье в 10:00 бот присылает в Telegram файл `nasha-kuhnya-ДАТА.json` со всеми данными. Восстановление: **Настройки → Загрузить копию**, выбрать этот файл. Workflow: `.github/workflows/backup.yml`, секреты те же, что у напоминаний.

## Если что-то поменяли в файлах

Загрузите изменённые файлы на GitHub так же, через **Add file → Upload files**. Если телефон упорно показывает старую версию, поменяйте в `sw.js` строку `const CACHE = 'kuhnya-v1'` на `v2`.
